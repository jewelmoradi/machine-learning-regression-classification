# Machine Learning: Regression and Classification

Coursework and hands-on practice from the **Supervised Machine Learning: Regression and Classification** course, part of the **Machine Learning Specialization** by DeepLearning.AI and Stanford Online.

## About

This repository contains my labs, programming assignments, and hands-on exercises completed throughout the course.

The repository is organized by course week and follows the original course structure.

## Course Topics

- Linear regression
- Multiple linear regression
- Gradient descent
- Feature scaling and feature engineering
- Logistic regression
- Classification
- Regularization
- Machine learning implementation with Python and NumPy
- Practical machine learning with scikit-learn
